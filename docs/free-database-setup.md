# Free cloud database setup for AlphaFund AI

## Recommended: Neon Postgres (free tier)

AlphaFund already uses SQLAlchemy and a relational portfolio schema. Neon provides managed PostgreSQL, so there is no database server to install or maintain.

The Neon Free plan currently includes 1 GB storage per project, 100 compute-hours per month, and 5 GB monthly public network transfer. Compute scales to zero when idle; the first connection after inactivity can take longer. Free-tier quotas and terms can change. Check the provider's current limits before relying on it for important records.

Official pages:
- Create a Neon project: https://console.neon.tech/
- Neon Free plan limits: https://neon.com/docs/introduction/plans
- Neon connection strings: https://neon.com/docs/connect/connect-from-any-app

### 1. Create the database

1. Sign in to Neon using your GitHub account.
2. Create a project named `alphafund-ai`.
3. Choose a region close to your Streamlit deployment where possible.
4. Open the project's **Connect** panel.
5. Select the main branch and database.
6. Copy the **pooled** connection string (the hostname usually contains `-pooler`).
7. Keep the connection string private. It contains the database password.

The connection string should look similar to this (example only):

```text
postgresql://USER:PASSWORD@ep-example-pooler.REGION.aws.neon.tech/DBNAME?sslmode=require
```

Do not copy this example literally. Use the real value generated by Neon.

### 2. Connect Streamlit Community Cloud

1. Open the AlphaFund app in Streamlit Community Cloud.
2. Open **App settings → Secrets**.
3. Add the following TOML entry, replacing the placeholder with the real Neon pooled connection string:

```toml
DATABASE_URL = "postgresql://USER:PASSWORD@YOUR-NEON-POOLER-HOST/DBNAME?sslmode=require"
```

4. Save the secrets and reboot/restart the app.

The app reads `DATABASE_URL` from Streamlit Secrets and uses it for the portfolio database. It normalizes PostgreSQL URLs to the installed Psycopg 3 SQLAlchemy driver. Missing tables are initialized by the app at startup.

### 3. Local development (optional)

Put the same setting in your local `.env` file:

```dotenv
DATABASE_URL=postgresql://USER:PASSWORD@YOUR-NEON-POOLER-HOST/DBNAME?sslmode=require
```

Then install requirements and run:

```bash
pip install -r requirements.txt
alembic upgrade head
pytest -q
streamlit run app.py
```

To switch back to local SQLite, remove the environment override or use:

```dotenv
DATABASE_URL=sqlite:///data/alphafund.db
```

### 4. Verify the connection

After restarting AlphaFund, open **Portfolio**. If the database connection is valid, the page should load and database-backed portfolio actions should work. You can also open the Neon SQL Editor and verify that tables such as `accounts`, `instruments`, `holdings`, `transactions`, `valuations`, and `import_batches` exist.

If you created the database before applying migrations, run `alembic upgrade head` once from a local terminal with the same `DATABASE_URL`.

## Alternative: Supabase Postgres

Supabase is also compatible with AlphaFund's SQLAlchemy database layer.

1. Create a project at https://supabase.com/dashboard.
2. Open **Project Settings → Database → Connection string**.
3. Copy the PostgreSQL connection string. Prefer the session pooler if your hosting environment needs IPv4 compatibility or has short-lived connections.
4. Set it as `DATABASE_URL` in Streamlit Secrets, as above.

Supabase Free currently includes a 500 MB database and 5 GB egress. Free projects may be paused after one week of inactivity. Review current limits at https://supabase.com/docs/guides/platform/billing-on-supabase.

## Important data-safety notes

- A free database is suitable for development and a personal prototype, not a backup strategy.
- Export periodic backups from the provider or use `pg_dump`; do not rely on a free-tier provider as the only copy of investment records.
- Keep the database URL only in Streamlit Secrets or a local untracked `.env`. Never commit it, paste it into GitHub issues, or send it in chat.
- Keep `APP_PASSWORD` configured. The database URL is not a user login.
- Groww API tokens and credentials are separate from the database credentials. AlphaFund does not store Groww secrets in PostgreSQL.
- The portfolio ledger is stored in this PostgreSQL database. The legacy paper-trading ledger still uses its separate SQLite file.
- If the Neon free compute quota is exhausted, database connections can be suspended until the quota resets or the plan changes. Check provider usage periodically.
